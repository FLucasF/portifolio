# Logos das ferramentas

Cada SVG foi convertido para uma cor só (`currentColor`), para seguir a cor do
texto nos dois temas. A cor oficial de cada marca fica em `src/data/logos.ts`.

As marcas pertencem aos seus donos e aparecem aqui só para identificar as
ferramentas.

- **Simple Icons** (https://simpleicons.org), licença CC0 1.0: quase todos,
  inclusive o "N" da Netflix, usado no Eureka (Netflix Eureka).
- **Devicon** (https://devicon.dev), licença MIT: `java.svg`, `playwright.svg` e a
  palavra da Oracle.
- **Javalin**: a esfera do logo oficial (https://javalin.io/img/logo.svg), sem a
  palavra e numa cor só, com o miolo escuro virando recorte.
- **Oracle**: a marca completa, com a cápsula redesenhada em vetor e a palavra
  ORACLE do Devicon (`oracle-original.svg`, licença MIT) embaixo.
